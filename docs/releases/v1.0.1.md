# btyper v1.0.1

Ctrl+K now toggles the virtual keyboard during a lesson. The shortcut follows
the physical key on English and Russian layouts and does not enter a character
into the lesson. The keyboard remains controlled by the existing setting; the
shortcut changes its visibility for the current lesson.

This patch does not change the database schema, backup format, profile format,
or supported platforms. Release binaries target Linux amd64/arm64, macOS
amd64/arm64, and Windows amd64.

Verification: [main CI](https://github.com/Ada-lave/btyper/actions/runs/35854492542)
and the [release workflow](https://github.com/Ada-lave/btyper/actions/runs/35854690716)
passed. Local `go test ./...`, `go test -race ./...`, `go vet ./...`,
`go build ./cmd/btyper`, shell syntax checks, Ruby formula syntax check, and
`makepkg --printsrcinfo` passed on Linux x86_64. The Ctrl+K regression test
covers English and Russian keyboard layouts and confirms the shortcut does not
enter lesson text. All five published binaries matched `checksums.txt`.

The Linux x86_64 `install.sh` path installed a binary reporting
`btyper v1.0.1` with the expected SHA-256; a fresh terminal launch reached the
main menu. `makepkg --verifysource` passed and
the AUR-compatible package built with the executable and license. Package
recipes match the published checksums.
