# btyper v1.2.0

- Add Btype typing tests with random words and history results without changing adaptive progress.
- Add an optional setting to continue typing after errors.
- Notify release builds about updates and add checksum-verified `btyper update` for Linux and macOS.

Database schema and portable backup format remain unchanged (format 1).
Backups containing Btype sessions require this version for import.

Manual accessibility, real-data backup round trips, macOS, Windows and arm64 execution were not tested locally.
