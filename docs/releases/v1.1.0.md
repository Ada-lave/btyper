# btyper v1.1.0

Training lessons now avoid repeatedly selecting the same words from a small
vocabulary. Bigram drills generate varied words while keeping the target pair.

The new `btyper dictionary download` command downloads English and Russian
FrequencyWords dictionaries; use `--lang en` or `--lang ru` for one language
and `--data-dir DIR` for a custom data directory. Downloaded words are loaded
automatically on the next launch and work offline. After filtering to 2–10
letters in the profile alphabet, the tested source provides 43,116 English
and 42,720 Russian words. Failed downloads preserve existing dictionary files.
The synthetic-word model is indexed once per lesson to handle larger lists.

Dictionary content comes from Hermit Dave's FrequencyWords / OpenSubtitles
2018 under CC BY-SA 4.0; attribution is retained in the downloaded files.
See [dictionary documentation](../dictionaries.md) for source and license links.
The btyper code remains MIT-licensed. Imported profiles keep their own words.

There is no database schema or backup format change. Portable backups remain
format 1; downloaded dictionaries are separate assets, outside backups.

Validation: local `just check` passed, including lint, vet, tests, race tests,
build and installer syntax. Real English and Russian downloads succeeded.
Regression tests cover variety, allowed letters, target skills, malformed
downloads, preservation of installed dictionaries, and service loading.

A v1.0.3 backup from a copy of real Linux data imported with matching 111
sessions, 57 progress entries, 257 skills and 126 practice-time entries.
Record contents matched after timezone normalization; a malformed import
preserved settings and all records. A Linux terminal smoke test covered the
main menu, a Russian lesson using the downloaded vocabulary and the pause menu.

Release binaries target Linux amd64/arm64, macOS amd64/arm64, and Windows
amd64. The full manual accessibility checklist was not run. macOS, Windows,
arm64 and screen-reader behavior were not tested locally. Publication,
checksum verification, previous-version backup compatibility and Linux
installation smoke-test results are recorded in the GitHub release notes.
