# btyper v1.1.1

`btyper -h` now lists all subcommands, including dictionary downloads,
profile management, and backup import/export, in English and Russian.
It includes an example for opening subcommand help. Requesting subcommand
help now exits successfully instead of reporting it as an error.

There are no database, backup format, dictionary or training changes.
Portable backups remain format 1.

Validation includes the full local `just check`, regression coverage for both
help languages, and CLI smoke tests for root and subcommand help. Publication,
asset checksums, Linux installation and backup compatibility results are
recorded in the GitHub release notes.

The full manual accessibility checklist, screen readers, macOS, Windows and
arm64 execution were not tested locally.
