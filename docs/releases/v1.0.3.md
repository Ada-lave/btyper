# btyper v1.0.3

This maintenance release fixes lint findings in CLI output, resource cleanup,
skill scheduling, and statistics navigation. It also restores the lint tool in
main CI. There is no database schema or backup format change; portable backups
remain format 1.

Release binaries target Linux amd64/arm64, macOS amd64/arm64, and Windows
amd64. The maintained installation channel on Linux and macOS is `install.sh`.

Local `just check` passed, including lint, tests, race tests, vet, build, and
installer syntax. A v1.0.2 backup exported from a copy of an existing Linux
data directory imported into v1.0.3 with equal counts for 63 sessions, 45
progress entries, 230 skills, and 66 practice-time entries. A malformed backup
was rejected and left all four counts unchanged.

The full manual accessibility checklist was not run. macOS, Windows, and
arm64 launches were not tested locally. CI, release assets, installation smoke
test, and SHA-256 checksums will be recorded after publication.
