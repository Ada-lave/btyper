# btyper v1.0.0

First stable release of the local-first terminal typing trainer.

Highlights since v0.1: adaptive letter/bigram review, digits/uppercase/
punctuation practice, focused Drill lessons, custom-text preview, daily
practice goals and streaks, weekly review, and importable JSON language
profiles. Portable JSON backup and CSV export remain available. The project
is licensed under MIT.

Supported release binaries: Linux amd64/arm64, macOS amd64/arm64 and Windows
amd64. Installation recipes for Homebrew, an AUR-compatible PKGBUILD and Scoop
are in the repository; they are not yet listed in central package registries.
See the [installation guide](https://github.com/Ada-lave/btyper/blob/main/docs/install.md)
and [stable compatibility contract](https://github.com/Ada-lave/btyper/blob/main/docs/stable-contract.md).

Upgrade: close btyper and copy the full data directory before running v1.0.0.
Schema migration is transactional. Do not run older binaries against a database
that has been upgraded. Format-1 JSON backups are supported; imported profiles
should be exported separately.

Verification: main CI and tag release workflow passed. The v1.0.0 Linux amd64
install.sh path reported `btyper v1.0.0` and matched the released SHA-256.
`makepkg --verifysource` and a full x86_64 AUR-compatible package build passed;
the package contains the executable and MIT license. Homebrew, Scoop, macOS,
Windows and arm64 installation paths have documented smoke tests but were not
executed on those hosts during this release. The accessibility checklist is
published for manual verification; no claim of cross-terminal accessibility
certification is made.
