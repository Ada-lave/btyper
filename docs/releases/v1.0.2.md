# btyper v1.0.2

Adaptive learning now has independent settings to include or exclude numbers,
uppercase letters, and special characters. All categories remain enabled by
default, including for existing installations. The settings are stored with
the existing local settings; no database schema or backup format change is
required.

Release binaries target Linux amd64/arm64, macOS amd64/arm64, and Windows
amd64.

Verification and published checksums will be recorded after the release
workflow completes.
