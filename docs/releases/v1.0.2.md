# btyper v1.0.2

Adaptive learning now has independent settings to include or exclude numbers,
uppercase letters, and special characters. All categories remain enabled by
default, including for existing installations. The settings are stored with
the existing local settings; no database schema or backup format change is
required.

Release binaries target Linux amd64/arm64, macOS amd64/arm64, and Windows
amd64.

The maintained installation channel is the checksum-verified `install.sh`
script for Linux and macOS. Package-manager releases are not provided.

Verification: local `just check` and [main CI](https://github.com/Ada-lave/btyper/actions/runs/35857274187)
passed. The [release workflow](https://github.com/Ada-lave/btyper/actions/runs/35857456231)
published all five binaries, `checksums.txt`, and `install.sh`; every binary
matched its named SHA-256 entry. On Linux x86_64, `install.sh` installed
`btyper v1.0.2` into a temporary directory and verified the checksum.

The full accessibility checklist and a manual previous-release data-directory
backup round trip were not run. The legacy backup settings behavior is covered
by an automated import regression test. Homebrew, AUR, and Scoop installation
smoke tests were not run. macOS,
Windows, and arm64 installer launches were not tested locally.
