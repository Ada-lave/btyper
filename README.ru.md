# btyper

[English](README.md) | **Русский**

Адаптивный тренажёр слепой печати в терминале. Тренируйте слабые буквы и пары,
печатайте на русском или английском и отслеживайте прогресс локально.
Вдохновлён циклом обучения Keybr.

![Демонстрация обучения печати в btyper](output.gif)

## Возможности

- **Адаптивные уроки:** начните с небольшого набора букв, затем тренируйте слабые
  навыки и возвращайтесь к тем, которым пора повторение.
- **Русский и английский:** встроенные раскладки, переведённый интерфейс и
  дополнительные большие словари.
- **Три способа практики:** адаптивное обучение, упражнения на выбранную букву
  или пару и собственный текст.
- **Наглядный прогресс:** скорость, точность, слабые клавиши, история, дневная цель
  и серия дней практики.
- **Локальное хранение:** аккаунт не нужен, обучение работает без интернета.
  Скачивание словарей необязательно, прогресс остаётся на вашем компьютере.

## Установка и запуск

На Linux или macOS ознакомьтесь с [install.sh](install.sh), затем установите
последний релиз и запустите программу:

```sh
curl -fsSL https://raw.githubusercontent.com/Ada-lave/btyper/main/install.sh | sh
btyper
```

Установщик проверяет SHA-256 бинарника и устанавливает его в `~/.local/bin`.
Этот каталог должен быть в `PATH`; также можно запустить `~/.local/bin/btyper`
напрямую. Для готового релиза Go не требуется.

Бинарник для Windows amd64 доступен на [странице релизов](https://github.com/Ada-lave/btyper/releases/latest).
Проверка контрольных сумм, выбор каталога установки и конкретной версии описаны
в [руководстве по установке](docs/install.md) (на английском).

Нужен терминал с UTF-8 размером не менее **60 столбцов × 16 строк**. При меньшем
размере урок приостанавливается. Релизы поддерживают Linux и macOS amd64/arm64,
а также Windows amd64.

## Первый урок

1. Запустите `btyper` и выберите адаптивное обучение.
2. Печатайте показанные слова. При ошибке нажмите Backspace перед продолжением.
3. Посмотрите скорость, точность и слабые буквы, затем начните следующий урок.

Обучение начинается с небольшого алфавита и постепенно добавляет буквы.
После буквенной базы программа планирует упражнения на пары и может включать
цифры, заглавные буквы и пунктуацию. Эти категории можно отключать в настройках.
При первом запуске язык обучения выбирается по языку интерфейса; изменить его
можно в настройках или через `btyper --lang ru` / `btyper --lang en`.

Для конкретной цели выберите «Тренировка буквы или пары», а для своего отрывка —
режим собственного текста: его можно вставить или открыть из UTF-8 файла.
Статистика показывает историю и прогресс, а в настройках есть дневная цель.

## Управление

| Клавиша | Действие |
| --- | --- |
| Стрелки или `j` / `k` | Навигация по меню |
| Enter | Выбор пункта или продолжение после урока |
| Esc во время урока | Меню паузы |
| Backspace | Исправление ошибки печати |
| Ctrl+R во время урока | Перезапуск урока |
| Ctrl+K во время урока | Показать или скрыть виртуальную клавиатуру |
| Ctrl+O / Ctrl+S в редакторе текста | Открыть файл / начать практику со своим текстом |
| PgUp / PgDn | Прокрутка длинных экранов |

Сочетания для навигации работают с русской и английской раскладками.
Справка по параметрам и подкомандам:

```sh
btyper -h
btyper dictionary download -h
```

## Дополнительные словари

Встроенный словарь доступен сразу. Для большего разнообразия настоящих слов:

```sh
btyper dictionary download            # русский и английский
btyper dictionary download --lang ru  # только русский
```

Скачанные словари используются при следующем запуске, в том числе без сети.
В уроки попадают только слова из открытых букв. Если для обучения задан
`--data-dir DIR`, укажите тот же параметр после `download`. Источник, фильтрация
и лицензия CC BY-SA 4.0 описаны в [руководстве по словарям](docs/dictionaries.md)
(на английском).

## Разработка

Склонируйте репозиторий. Нужны версия Go из [go.mod](go.mod) и `just`:

```sh
git clone https://github.com/Ada-lave/btyper.git
cd btyper
just build
/tmp/btyper --data-dir /tmp/btyper-dev
just check
```

`just run` запускает исходники; `just install` устанавливает бинарник в `GOBIN`
или `$(go env GOPATH)/bin`. Отдельные проверки: `just test`, `just test-race`,
`just vet`. Публикация описана в [чек-листе релиза](docs/release-checklist.md).
